IA local: modelos que funcionan en tu computador

Copilot, Claude, ChatGPT y Gemini funcionan en servidores de cada empresa. La IA local descarga un modelo de pesos abiertos y lo ejecuta en tu propio equipo, sin enviar los textos a internet.

Instalar software requiere autorización

En un computador del Gobierno Regional, instalar estas herramientas o descargar modelos debe pasar por el área TI. Que los datos no salgan del equipo no elimina las obligaciones de la ley de protección de datos ni el semáforo: solo cambia dónde se procesan.

Buen uso

Cuándo conviene

  • Documentos internos que no deben salir del equipo, una vez autorizado su uso.
  • Clasificar o resumir grandes volúmenes de texto sin consumir cuotas.
  • Lugares sin conexión estable.
  • Aprender cómo funcionan los modelos por dentro.
Precaución

Cuándo no conviene

  • Análisis jurídicos o cálculos donde un error cuesta caro: los modelos pequeños alucinan más.
  • Equipos con menos de 16 GB de memoria.
  • Cuando nadie en la unidad puede mantenerlo y actualizarlo.

Herramientas

GratisWindows · macOS · Linux

LM Studio

La más amigable: una aplicación con ventanas para buscar, descargar y conversar con modelos. Gratis también para uso laboral. Trae cliente MCP para conectar herramientas.

GratisWindows · macOS · Linux

Ollama

Pensada para usarse desde la terminal y conectarse con otros programas. Descargas un modelo con una línea y queda disponible para otras aplicaciones del computador.

Código abiertoAvanzado

Hermes

Nous Research publica dos cosas con este nombre: los modelos Hermes, de pesos abiertos, que se pueden cargar en Ollama o LM Studio; y Hermes Agent, un agente de código abierto con memoria, Skills que crea solo y tareas programadas, que funciona con modelos locales o en la nube.

Código abierto

Jan y GPT4All

Aplicaciones de escritorio parecidas a LM Studio, enfocadas en privacidad y en conversar con tus documentos.

Código abiertoAvanzado

Open WebUI

Una interfaz web estilo ChatGPT sobre Ollama. Permite que el área TI instale un servidor interno y que varias personas lo usen desde el navegador.

Código abiertoAvanzado

llama.cpp

El motor que usan por dentro LM Studio y Ollama. Para quien quiere el máximo control y rendimiento.

Modelos de pesos abiertos

Se descargan una vez y se usan sin conexión. Se nombran por familia y tamaño: «8B» significa 8 mil millones de parámetros. Más grande suele ser mejor, pero exige más equipo.

Qwen (Alibaba)

Muy buenos en español y en tareas con herramientas. Varios tamaños.

Gemma (Google)

Livianos y de buena calidad para su tamaño, algunos entienden imágenes.

gpt-oss (OpenAI)

Modelos de razonamiento de pesos abiertos. El de 20B funciona en un computador con 16 GB de memoria.

Llama (Meta) y Mistral

Familias muy difundidas, con muchas variantes ajustadas por la comunidad.

DeepSeek

Modelos de razonamiento; las versiones completas son muy grandes, las reducidas caben en equipos comunes.

Hermes (Nous Research)

Variantes ajustadas para seguir instrucciones y usar herramientas.

Revisa la licencia de cada modelo

«Pesos abiertos» no siempre significa uso libre. Algunos modelos usan licencias permisivas (como Apache 2.0) y otros tienen condiciones propias. Antes de usarlo en el trabajo, revisa la licencia en su página de descarga.

Cómo empezar

Con LM Studio (sin terminal)

  1. Descarga e instalaDesde lmstudio.ai, con autorización del área TI.
  2. Busca un modeloEn la pestaña de búsqueda escribe, por ejemplo, «qwen» o «gemma». LM Studio indica si el modelo cabe en tu equipo.
  3. Cárgalo y conversaElige el modelo arriba y escribe como en cualquier chat. Puedes arrastrar un PDF a la conversación.
  4. ComparaHaz la misma pregunta en Copilot y en el modelo local, y compara calidad y tiempo.

Con Ollama (terminal)

  1. InstalaDesde ollama.com.
  2. Descarga y abre un modeloEn la terminal: ollama run gpt-oss:20b. La primera vez descarga varios GB.
  3. ConversaEscribe en la misma terminal; /bye para salir.
  4. ConéctaloOtras aplicaciones (Open WebUI, Hermes Agent, editores de código) usan Ollama como motor.
Prueba para comparar un modelo local con Copilot
Resume el siguiente texto en 5 viñetas para una jefatura, indica las fechas y montos que aparecen y señala con [NO ENCONTRADO] lo que falte para tomar una decisión.
TEXTO: [pega un texto público o ficticio, por ejemplo uno del kit del curso]

Usa los documentos ficticios del curso para probar: son ideales para comparar herramientas sin riesgo.

Agentes locales Avanzado

Un modelo local también puede ser el cerebro de un agente, con las mismas piezas de las otras plataformas: un harness, Skills y conectores MCP.

LM Studio + MCP

LM Studio incluye cliente MCP: puedes conectarle, por ejemplo, un servidor que lea una carpeta local, y todo queda en el equipo.

Hermes Agent

Un harness de código abierto (licencia MIT) para Windows, macOS y Linux. Recuerda conversaciones, crea sus propias Skills y ejecuta tareas programadas. Puede usar un modelo local o uno en la nube.

Servidor interno

El área TI puede instalar Ollama y Open WebUI en un servidor de la red del Gobierno Regional, para que varias unidades usen un modelo sin que los datos salgan de la institución.

Un agente local también se equivoca

Con un modelo más pequeño, el agente comete más errores al usar herramientas. Mantén a una persona revisando, dale permisos mínimos y no lo conectes a correo ni a sistemas que modifiquen datos sin supervisión.
